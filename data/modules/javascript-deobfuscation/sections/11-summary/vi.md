# Summary (Tổng kết)


Chúc mừng bạn đã hoàn thành module `JavaScript Deobfuscation`. Hy vọng giờ đây bạn đã có thể nhận ra các script bị obfuscate, deobfuscate chúng, decode output của chúng và tái hiện các chức năng của chúng.

Sau đây là tóm tắt những gì ta đã học:
- Đầu tiên, ta làm lộ ra source code `HTML` của trang web và tìm vị trí code JavaScript.
- Sau đó, ta học về nhiều cách khác nhau để obfuscate code JavaScript.
- Tiếp đó, ta học cách beautify và deobfuscate code JavaScript đã bị minify và obfuscate.
- Kế tiếp, ta đọc qua code đã deobfuscate và phân tích hàm chính của nó
- Sau đó, ta học về HTTP request và đã tái hiện được hàm chính của đoạn code JavaScript bị obfuscate.
- Cuối cùng, ta học về nhiều phương pháp encode và decode chuỗi.
